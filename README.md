# 丰巢快递柜 · Home Assistant 集成

通过丰巢 App 的 API 获取**待取件包裹**信息（柜子地址、取件码、格口、快递公司、到站时间、18h 收费倒计时等），并自动刷新。

## 功能

- **10 个传感器**：
  - 待取件数量（含完整包裹列表属性）
  - 最新快递公司 / 运单号 / 柜子地址 / 格口 / 取件码 / 到站时间
  - 收费倒计时 / 收费时间（18h 免费期结束）
  - 超时费合计
- **手机号 + 短信验证码登录**（无需抓包）
- **15 分钟自动刷新**（可改 `const.py` 里的 `UPDATE_INTERVAL_MINUTES`）
- **重新登录**：集成 → 配置 → 重新走登录流程（token 过期时用）

## 安装

### 手动

1. 下载本仓库
2. 把 `custom_components/fcbox` 复制到你的 HA 配置目录 `custom_components/` 下
3. 重启 Home Assistant

### HACS（自定义仓库）

1. HACS → 集成 → 右上角菜单 → 自定义仓库
2. 添加 `https://github.com/<你的用户名>/fcbox-ha`
3. 搜索「丰巢快递柜」安装
4. 重启 HA

## 配置

设置 → 设备与服务 → 添加集成 → 搜索「丰巢快递柜」：

1. 输入手机号 → 提交（会发送短信验证码）
2. 输入收到的验证码 → 完成登录

**注意**：
- 同一手机号 1 分钟内只能发一次验证码
- 退出丰巢 App / 重新登录会让旧 token 失效，需要在本集成里重新登录

## 原理

> ⚠️ 本集成使用非官方 API（抓包逆向），仅供个人学习使用。接口可能随时变更。
>
> - 登录：`secureCheckMobile` / `secureSendCode` / `secureLoginByPhone`（`sign` 参数服务端不验签，任意非空即可）
> - 拉取：`POST /post/express/toPickList`
> - 认证：登录响应头 `Authorization`
